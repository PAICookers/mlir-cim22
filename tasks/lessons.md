# Lessons

- File counts and 64-bit syntax are not a frame protocol oracle. Compare
  decoded addresses, values, routes, and recipients with independent evidence.
- LLVM supplies integer/container/pass facilities, not CIM22-specific body
  fields. Keep the minimal shared payload encoder in the existing target codec;
  leave TB-specific high bits and the physical response endpoint in the exporter.
- A compiler ingress and an off-chip response destination are separate
  contracts. Returning to self is not a response-disable mechanism.
- Merge equal-payload recipients only when the emitted route covers the exact
  set. A supplier full-chip example is not a model's allocation.
