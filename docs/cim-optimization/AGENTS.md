# CIM 优化文档按需读取规则

本规则仅用于与 CIM 优化有关的任务。无关任务跳过本目录。任务点名文件时直接打开该文件。仅查询优化项或完成状态时，只读 [README.md](README.md)。

| 任务 | 首读 |
| --- | --- |
| 列块化、调度、编译内存、Host 缓冲区或模拟器 | [编译与软件执行](design.md#编译与软件执行) |
| 计算启动、USB 回读或 PLL | [USB 运行时](design.md#usb-运行时) |
| 权重驻留、失效或 FC/Linear 重排 | [权重驻留与重排](design.md#权重驻留与-fclinear-重排) |
| 设计回归或判断验证范围 | [验收范围](design.md#验收范围) |
| 统计公式、计数单位或等待项 | [计数口径](operation-counts.md#计数口径) |
| 基准结果或前后对照 | [单算子](operation-counts.md#单算子conv-与-matmul)、[DVS](operation-counts.md#dvsgesture-t32-全模型) 或 [Host 内存](operation-counts.md#host-内存里程碑) |

1. 先按表定位标题，再读相关小节。遇到影响当前结论的依赖时才跟进链接。结论涉及当前实现时核对对应源码或测试。
2. 同一任务复用已读内容。委派子任务时只传递相关小节、关键约束和需验证的问题。目录级重组或用户要求全量审查时才遍历全目录。
3. 更新时只改对应技术文档。实现状态或验收范围发生变化时同步索引。已核对且可复现的里程碑进入结果页，调试记录留在本地。
