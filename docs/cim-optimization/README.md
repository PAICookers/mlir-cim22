# CIM 优化状态与设计索引

本目录面向维护 CIM 编译器和运行时的开发者。下表区分实现状态和验收范围。基准采用的输入、版本及统计口径见[基准条件](operation-counts.md#基准条件)。

| 优化项 | 实现状态 | 已覆盖的验证 | 详细设计 |
| --- | --- | --- | --- |
| 自动列块化与独立计算合批 | 已实现，默认 `auto` | INT8/BF16 软件差分、尾块和多核调度计数 | [列块调度](design.md#列块化与计算合批) |
| 多核按 Macro 批量回读 | 已实现 | USB 设备替身的乱序、分片和故障用例 | [USB 读回](design.md#按-macro-批量回读) |
| Once 后省略 Idle | 已实现 | 板卡程序与 USB 设备替身 | [计算启动](design.md#计算启动与写回屏障) |
| 同频 PLL 状态复用 | 已实现 | 串口替身的同频、变频和回显失败 | [PLL 生命周期](design.md#pll-状态复用) |
| 权重驻留与 FC/Linear 重排 | 已实现 | INT8/BF16 代表算子、USB 设备替身、整网静态重放 | [权重驻留](design.md#驻留身份与生命周期) |
| 模拟器静态绑定缓存和按需状态 | 已实现 | 软件执行、跨调用及缓冲区别名回归 | [模拟器](design.md#模拟器状态与静态绑定) |
| 模型加载与原生编译内存 | 已实现 | 制品加载、编译和运行时回归 | [模型加载与原生编译](design.md#模型加载与原生编译) |
| Host 释放拆分、单位维折叠/逐元素融合与 Transaction 输入布局 | 已实现，默认启用 | Host IR lit、BF16/INT8 软件差分、DVS 原生对象与 simulator 重复执行 | [Host 缓冲区](design.md#host-缓冲区与-lif-切片) |
| Host 提前释放与 LIF 切片写入 | 已实现 | 所有权回归和整网输出/状态对照 | [Host 缓冲区](design.md#host-缓冲区与-lif-切片) |
| 跨算子数学融合 | 暂缓 | 部署需要独立数值证明 | [融合边界](design.md#跨算子融合边界) |

USB 优化的组合实板验收，以及开启 FC/Linear 重排后的完整 DVS 原生推理验收待完成。静态计数、软件结果和设备替身结果按[验收范围](design.md#验收范围)分别使用。

- [计数口径与基准](operation-counts.md)定义发送批次、协议记录和等待项，汇总单算子、DVS 整网和 Host 内存结果。
- [Agent 按需读取规则](AGENTS.md)按任务类型选择入口。
